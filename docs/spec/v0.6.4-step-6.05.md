## 1. Genel Amaç ve Kapsam

Bu adımda, Pulse ekosisteminin ilk **LLM destekli (Tier B — AI Assisted)** ajanları hayata geçirilir:

1. **Agent-005 (Asenkron Günlük Standup — Async Daily Standup):**
   - Her sabah ekip üyelerine proje panosu üzerinde "Günlük Standup" bildirim kartı ve modalı sunar.
   - Üyelerden 3 kritik sorunun yanıtını toplar: *"Dün ne yaptın?", "Bugün ne yapacaksın?", "Karşılaştığın bir engel var mı?"*.
   - Toplanan yanıtları LLM (Bulutistan/OpenAI-compatible) kullanarak takım bazında sentezler, engelleri vurgular ve panoda "Günün Standup Özeti" bülteni olarak yayınlar.
2. **Agent-006 (Haftalık Sprint Özeti — Weekly Sprint Digest):**
   - Her Cuma saat 17:00'de haftalık sprint metriklerini (tamamlanan işler, velocity, kalan riskler, darboğazlar) derler.
   - LLM ile yönetim seviyesinde haftalık sağlık raporu üretir ve proje yöneticilerine sunar.
3. **Sıfır Hata Prensibi (Zero-Failure Fallback):**
   - LLM API anahtarı girilmemişse veya ağ hatası olursa sistem çökmeyecek; kural tabanlı deterministik özetleyici (heuristic fallback) devreye girecektir.

## 2. Veritabanı Modelleri

`prisma/schema.prisma` dosyasına eklenecek yeni modeller:

```prisma
model DailyStandup {
  id          String   @id @default(cuid())
  projectId   String
  date        DateTime @default(now()) // Gün bazlı tarih (YYYY-MM-DD)
  summary     String?  @db.Text        // LLM tarafından derlenen takım özeti
  blockers    Json?                    // Tespit edilen acil engeller listesi
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  project     Project  @relation(fields: [projectId], references: [id], onDelete: Cascade)
  entries     StandupEntry[]

  @@unique([projectId, date])
  @@index([projectId])
}

model StandupEntry {
  id          String   @id @default(cuid())
  standupId   String
  userId      String
  yesterday   String   @db.Text
  today       String   @db.Text
  blockers    String?  @db.Text
  submittedAt DateTime @default(now())

  standup     DailyStandup @relation(fields: [standupId], references: [id], onDelete: Cascade)
  user        User         @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([standupId, userId])
  @@index([userId])
}
```

## 3. Agent-005: Asenkron Standup (Async Daily Standup)

### 3.1 Döngü ve Tetikleme
- **09:30:** Proje aktifse ve `agent-005` enabled ise günün `DailyStandup` kaydı açılır.
- Ekip üyeleri panoya girdiğinde üst kısımda *"Günlük Standup'ınızı Yanıtlayın"* kartı görür.
- **11:30 (Cut-off):** Python Agent konteyneri (`agent/src/agents/agent_005.py`) tetiklenir:
  - Girilen tüm `StandupEntry` yanıtlarını çeker.
  - LLM istemine (prompt) iletir:
    ```
    Rol: Kıdemli Çevik Proje Yöneticisi Asistanı
    Girdi: Ekip üyelerinin dün, bugün ve engel yanıtları.
    Çıktı: Markdown formatında:
      - 🚀 Genel İlerleme Özeti
      - 👤 Üye Bazlı Özet (Maddeler halinde)
      - ⚠️ Varsa Kritik Engeller (Kırmızı bayraklar)
    ```
  - Derlenen özet `DailyStandup.summary` alanına yazılır.
  - Ekibe özetin yayınlandığına dair bildirim gider.

### 3.2 UI Bileşenleri
- `src/components/standup/standup-banner.tsx`: Panonun üstünde yanıt verilmemişse görünen davet banner'ı.
- `src/components/standup/standup-modal.tsx`: 3 soruluk hızlı giriş modalı.
- `src/components/standup/standup-summary-card.tsx`: Yayınlanan özetin şık, okunabilir kart görünümü.

## 4. Agent-006: Haftalık Rapor (Weekly Sprint Digest)

### 4.1 Tetikleme
- Her **Cuma 17:00 (Europe/Istanbul)** APScheduler tarafından çalıştırılır.
- Aktif sprintin metrikleri toplanır:
  - Bu hafta tamamlanan görev sayısı ve tahmini story point'ler.
  - Devam eden işler ve geciken görevler.
  - Sprint hız (velocity) trendi ve bitiş tarihine kalan gün sayısı.

### 4.2 LLM Raporlama Formatı
- LLM promptuna iletilen ham analitik verilerden şık bir haftalık bülten oluşturulur:
  ```markdown
  ### 📊 Haftalık Sprint Karnesi (Hafta {X})
  - **Sprint Durumu:** [Zamanında / Riskli / Geride]
  - **Bu Hafta Tamamlanan:** {X} Görev
  - **Öne Çıkan Başarılar:** ...
  - **Önümüzdeki Haftanın Öncelikleri:** ...
  ```
- Rapor proje ADMIN / PM'lerine bildirim olarak iletilir ve Aktivite akışına (`Activity.isAiGenerated: true`) kaydedilir.
