## 1. Genel Amaç ve Kapsam

Bu adımda, Pulse projesine derin bir **kurumsal hafıza (Project Memory)** ve **semantik arama (RAG / Semantic Search)** yeteneği kazandırılır:

1. **pgvector Eklentisi:** `docker-compose.yml` içindeki PostgreSQL konteyneri `pgvector/pgvector:pg16` imajına geçirilerek vektör benzerlik araması (`vector` veri tipi ve cosine similarity `<=>`) aktif edilir.
2. **Görev ve Doküman Vektörleştirme (Embedding Pipeline):**
   - Görevler (`title`, `description`), yorumlar ve standup özetleri oluşturuldukça veya güncellendikçe arka planda metin gömmeleri (embeddings) oluşturularak veritabanına indekslenir.
3. **Akıllı Komut Paleti (Cmd+K) & Benzer Görev Arama:**
   - Kullanıcı Cmd+K arama çubuğunda doğal dille sorgu yaptığında (örn. *"ödeme sayfasındaki hata"*), başlıkta tam kelime geçmese bile semantik olarak ilişkili tüm görevler ve geçmiş çözümler listelenir.
   - Görev detayında *"İlişkili Olabilecek Görevler"* öneri paneli sunulur.

## 2. Altyapı ve Veritabanı Değişiklikleri

### 2.1 Docker Compose Güncellemesi
`docker-compose.yml` içindeki `db` servisi pgvector destekli resmi imaja güncellenir:
```yaml
  db:
    image: pgvector/pgvector:pg16
    container_name: pulse-postgres
    # ...
```

### 2.2 Veritabanı Tablosu
```sql
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE "TaskEmbedding" (
  "id" TEXT PRIMARY KEY,
  "taskId" TEXT NOT NULL REFERENCES "Task"("id") ON DELETE CASCADE,
  "embedding" vector(1536), -- veya seçilen model boyutu
  "contentHash" TEXT NOT NULL,
  "updatedAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX task_embedding_cosine_idx ON "TaskEmbedding" USING ivfflat ("embedding" vector_cosine_ops) WITH (lists = 100);
```

## 3. Semantik Arama Mantığı (`src/lib/semantic-search.ts`)

1. **Metin Hazırlığı:** Görev başlığı, etiketi ve açıklaması birleştirilerek gömme metni oluşturulur:
   `"[PRJ-12] Ödeme Entegrasyonu: Stripe webhook hataları çözüldü."`
2. **Embedding Üretimi:** `ai/embeddings.ts` üzerinden OpenAI-compatible embedding API çağrılır.
3. **Vektör Benzerlik Sorgusu:**
   ```sql
   SELECT t."id", t."title", t."sequenceId", 1 - (e."embedding" <=> %(queryVector)s) AS similarity
   FROM "TaskEmbedding" e
   JOIN "Task" t ON e."taskId" = t."id"
   WHERE t."projectId" = %(projectId)s
   ORDER BY similarity DESC
   LIMIT 10;
   ```
4. **Hibrit Sıralama (Hybrid Search):** Hem geleneksel metin araması (Trigram/Like) hem de vektör benzerliği birleştirilerek en alakalı sonuçlar döndürülür.
