## 1. Genel Amaç ve Kapsam

Bu adımda:
1. **Agent-001 (Deadline Takipçisi):** Sıfır (0) LLM token harcayan, tamamen deterministik kural motoruna dayalı Deadline Takip Agent'ı hayata geçirilir.
2. **Eski Oturuma Bağlı Fonksiyonun Yer Değişimi:** `src/actions/notification.ts` içindeki oturuma bağımlı ve eksik çalışan `checkApproachingDueDates` fonksiyonu kaldırılarak/refaktör edilerek, oturumdan bağımsız, proje bazlı çalışan `dispatchDueDateReminders(projectId: string, now: Date)` servisi oluşturulur.
3. **Eskalasyon Mantığı:** Günü geçen (overdue) görevler hem atanan kişilere bildirilir hem de projedeki tüm `ADMIN` rolüne sahip yöneticilere eskalasyon olarak iletilir.

5. **Dashboard "Agent Aktiviteleri" Widget'ı:** Dashboard ana sayfasına son 7 günde asistanın gerçekleştirdiği deadline hatırlatmalarını ve eskalasyonları gösteren şık bir kart eklenir.

## 2. Kural ve Bildirim Mantığı (Agent-001)

### 2.1 Zamanlama ve Tetikleme
- Her sabah saat **09:00 (Europe/Istanbul)** APScheduler tarafından veya startup catch-up sırasında tetiklenir.
- Agent-000 (Supervisor) projenin `AgentSettings` tablosunda `agent-001` için `enabled === true` olup olmadığını kontrol eder. Kapalıysa çalıştırmayı atlar (`status = 'SKIPPED'`).

### 2.2 Görev Filtreleme Kriterleri
Projede şu kriterleri sağlayan görevler çekilir:
- `dueDate != null`
- `state.group NOT IN ['DONE', 'CANCELLED']`
- Görevin atananları (`assignees`) ve durumu (`state`) dahil edilir.

### 2.3 Hatırlatma ve Eskalasyon Eşikleri
`clock.getNow()` (veya iletilen `now`) baz alınarak takvim günü farkı hesaplanır:
1. **3 Gün Kala (`daysRemaining === 3`):**
   - Hedef: Görevin tüm atananları (`assignees`).
   - Tip: `DUE_DATE_APPROACHING`
   - Başlık: `"[PM Adı] adına Pulse Asistan"`
   - Mesaj: `"[PRJ-X] {Görev Başlığı} görevinin teslimine 3 gün kaldı."`
2. **1 Gün Kala (`daysRemaining === 1`):**
   - Hedef: Görevin tüm atananları.
   - Tip: `DUE_DATE_APPROACHING`
   - Başlık: `"[PM Adı] adına Pulse Asistan"`
   - Mesaj: `"[PRJ-X] {Görev Başlığı} görevinin teslimine 1 gün kaldı! Lütfen durumunu kontrol edin."`
3. **Bugün Teslim (`daysRemaining === 0`):**
   - Hedef: Görevin tüm atananları.
   - Tip: `DUE_DATE_APPROACHING`
   - Başlık: `"[PM Adı] adına Pulse Asistan (Acil)"`
   - Mesaj: `"[PRJ-X] {Görev Başlığı} görevi bugün teslim edilmeli!"`
4. **Gecikmiş Görevler (`daysRemaining < 0` — Overdue):**
   - Hedef 1: Görevin tüm atananları.
     - Tip: `DUE_DATE_APPROACHING`
     - Başlık: `"[PM Adı] adına Pulse Asistan (Gecikme)"`
     - Mesaj: `"[PRJ-X] {Görev Başlığı} görevinin teslim tarihi {N} gün geçti."`
   - Hedef 2 (Eskalasyon): Projede `role === 'ADMIN'` olan tüm üyeler.
     - Tip: `DUE_DATE_APPROACHING`
     - Başlık: `"[Eskalasyon] Geciken Görev Uyarısı"`
     - Mesaj: `"[PRJ-X] {Görev Başlığı} görevi {N} gün gecikti. Atananlar: {İsimler}"`

### 2.4 İdempotenlik (Mükerrer Bildirim Engeli)
Aynı takvim gününde (gece 00:00'dan sonra) aynı görev için aynı kullanıcıya birden fazla `DUE_DATE_APPROACHING` bildirimi yazılmamalıdır:
```typescript
const alreadySent = await prisma.notification.findFirst({
  where: {
    userId: recipientId,
    type: "DUE_DATE_APPROACHING",
    link: { contains: taskId },
    createdAt: { gte: startOfToday },
  },
});
if (alreadySent) continue;
```

### 2.5 Kullanıcı Bildirim Tercihleri
Mevcut `shouldDeliverWithPreferences` fonksiyonu ile alıcının `notifyDueDateApproaching` ayarı kontrol edilmelidir. Tercih kapalıysa bildirim yazılmaz.

## 3. Next.js Servis Katmanı (`src/lib/deadline-tracker-service.ts`)

Oturumdan bağımsız servis fonksiyonu:

```typescript
// src/lib/deadline-tracker-service.ts
import { prisma } from "@/lib/prisma";
import { getNow } from "@/lib/clock";
import { shouldDeliverWithPreferences } from "@/lib/notification-preferences";
import { buildNotificationDeepLink } from "@/lib/notification-logic";
import { Prisma } from "@prisma/client";

export interface DeadlineCheckResult {
  tasksScanned: number;
  remindersSent: number;
  escalationsSent: number;
  skippedDueToPreferences: number;
}

export async function dispatchDueDateReminders(
  projectId: string,
  now: Date = getNow()
): Promise<DeadlineCheckResult> {
  // 1. Proje, PM Kullanıcısı ve Adminleri Çek
  const project = await prisma.project.findUnique({
    where: { id: projectId },
    include: {
      owner: { select: { id: true, name: true } },
      members: {
        where: { role: "ADMIN" },
        include: { user: { select: { id: true, name: true } } },
      },
      agentSettings: {
        where: { agentKey: "agent-001" },
        include: { pmUser: { select: { id: true, name: true } } },
      },
    },
  });

  if (!project) {
    throw new Error(`Project ${projectId} not found`);
  }

  const agentSetting = project.agentSettings[0];
  if (agentSetting && !agentSetting.enabled) {
    return { tasksScanned: 0, remindersSent: 0, escalationsSent: 0, skippedDueToPreferences: 0 };
  }

  const pmName = agentSetting?.pmUser?.name || project.owner.name;
  const adminUsers = project.members.map((m) => m.user);

  // 2. Aktif görevleri getir
  const tasks = await prisma.task.findMany({
    where: {
      projectId,
      dueDate: { not: null },
      state: { group: { notIn: ["DONE", "CANCELLED"] } },
    },
    include: {
      assignees: { include: { user: { select: { id: true, name: true } } } },
      state: { select: { name: true, group: true } },
    },
  });

  const startOfToday = new Date(now);
  startOfToday.setHours(0, 0, 0, 0);

  let remindersSent = 0;
  let escalationsSent = 0;
  let skippedDueToPreferences = 0;

  const notificationsToCreate: Prisma.NotificationCreateManyInput[] = [];

  for (const task of tasks) {
    if (!task.dueDate) continue;

    // Gün farkı hesabı (takvim günü bazında)
    const taskDueDate = new Date(task.dueDate);
    taskDueDate.setHours(0, 0, 0, 0);
    const diffTime = taskDueDate.getTime() - startOfToday.getTime();
    const daysRemaining = Math.round(diffTime / (1000 * 60 * 60 * 24));

    // Yalnızca 3, 1, 0 veya gecikmiş (<0) görevler işleme alınır
    if (daysRemaining > 3 || (daysRemaining < 3 && daysRemaining > 1)) {
      continue;
    }

    const link = buildNotificationDeepLink(projectId, task.id);

    // A. Atananlara Hatırlatma
    for (const assignee of task.assignees) {
      const recipientId = assignee.user.id;

      // İdempotenlik kontrolü
      const alreadySent = await prisma.notification.findFirst({
        where: {
          userId: recipientId,
          type: "DUE_DATE_APPROACHING",
          link: { contains: task.id },
          createdAt: { gte: startOfToday },
        },
      });
      if (alreadySent) continue;

      // Tercih kontrolü
      const prefs = await prisma.userNotificationPreference.findUnique({
        where: { userId: recipientId },
      });
      if (!shouldDeliverWithPreferences({ actorId: null, recipientId, type: "DUE_DATE_APPROACHING", preferences: prefs })) {
        skippedDueToPreferences++;
        continue;
      }

      let title = `${pmName} adına Pulse Asistan`;
      let message = `"${task.title}" görevinin teslimine ${daysRemaining} gün kaldı.`;
      if (daysRemaining === 0) {
        title = `${pmName} adına Pulse Asistan (Acil)`;
        message = `"${task.title}" görevi bugün teslim edilmeli!`;
      } else if (daysRemaining < 0) {
        const daysOverdue = Math.abs(daysRemaining);
        title = `${pmName} adına Pulse Asistan (Gecikme)`;
        message = `"${task.title}" görevinin teslim tarihi ${daysOverdue} gün geçti.`;
      }

      notificationsToCreate.push({
        type: "DUE_DATE_APPROACHING",
        title,
        message,
        link,
        userId: recipientId,
        actorId: null,
      });
      remindersSent++;
    }

    // B. Gecikmişse Adminlere Eskalasyon
    if (daysRemaining < 0) {
      const daysOverdue = Math.abs(daysRemaining);
      const assigneeNames = task.assignees.map((a) => a.user.name).join(", ") || "Atanan yok";

      for (const admin of adminUsers) {
        // İdempotenlik
        const alreadyEscalated = await prisma.notification.findFirst({
          where: {
            userId: admin.id,
            type: "DUE_DATE_APPROACHING",
            link: { contains: task.id },
            title: { contains: "Eskalasyon" },
            createdAt: { gte: startOfToday },
          },
        });
        if (alreadyEscalated) continue;

        notificationsToCreate.push({
          type: "DUE_DATE_APPROACHING",
          title: `[Eskalasyon] Geciken Görev Uyarısı`,
          message: `"${task.title}" görevi ${daysOverdue} gün gecikti. Atananlar: ${assigneeNames}`,
          link,
          userId: admin.id,
          actorId: null,
        });
        escalationsSent++;
      }
    }
  }

  if (notificationsToCreate.length > 0) {
    await prisma.notification.createMany({
      data: notificationsToCreate,
    });
  }

  return {
    tasksScanned: tasks.length,
    remindersSent,
    escalationsSent,
    skippedDueToPreferences,
  };
}
```

## 4. Python Agent-001 Graph (`agent/src/agents/agent_001.py`)

Python tarafında APScheduler tarafından her sabah çağrılacak Agent-001 iş akışı:

```python
# agent/src/agents/agent_001.py
import logging
from datetime import datetime
from src.clock import get_now
from src.internal_client import InternalClient
from src.db import get_db_connection

logger = logging.getLogger("agent.001")

class DeadlineTrackerAgent:
    def __init__(self, internal_client: InternalClient):
        self.client = internal_client

    async def run_for_project(self, project_id: str, scheduled_for: datetime) -> dict:
        now = get_now()
        logger.info(f"Running Agent-001 for project {project_id} at {now}")

        # 1. Next.js Internal API üzerinden deadline kontrolünü tetikle
        result = await self.client.trigger_deadline_check(project_id)

        # 2. AgentRun tablosuna kayıt oluştur
        await self.client.record_run({
            "agentKey": "agent-001",
            "projectId": project_id,
            "scheduledFor": scheduled_for.isoformat(),
            "status": "SUCCESS" if result else "FAILED",
            "result": result or {},
            "tokenCount": 0,
        })

        return result
```

  - İstatistik Sayaçları:
    - 📅 **Hatırlatmalar:** Gönderilen son teslim tarihi bildirim sayısı.
