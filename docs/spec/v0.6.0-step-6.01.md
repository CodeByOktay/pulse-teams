## 1. Genel Amaç ve Kapsam

Bu adımın amacı, Pulse projesine proaktif AI Agent sisteminin altyapısını kurmaktır:
1. **Veritabanı Modelleri:** `DomainEvent` (outbox), `AgentRun` (çalışma logu), `AgentSettings` (proje bazlı ayarlar).
2. **Saat Soyutlaması (`Clock`):** Hem TypeScript hem Python tarafında test edilebilir `getNow()` / `get_now()` fonksiyonları.
3. **DomainEvent Outbox Mekanizması:** Next.js Server Action'ları transaction içinde DomainEvent yazar; Python container `SKIP LOCKED` ile tüketir.
4. **Next.js Internal API (HMAC Korumalı):** Python container'ın bildirim ve istek oluşturabilmesi için `/api/internal/agent/*` rotaları ve SHA256 imza doğrulaması.
5. **Python Container İskeleti (`pulse-agent`):** `agent/` dizini altında Dockerfile, requirements.txt, PostgreSQL bağlantısı, APScheduler, Startup Catch-up ve Agent-000 Supervisor iskeleti.
6. **Docker Compose Entegrasyonu:** `pulse-db` + `pulse-app` + `pulse-agent` üçlü konteyner mimarisi.
7. **Proje Ayarları UI:** Proje ayarlarında "AI Ajanlar" sekmesi (`AgentSettingsManager`) ve PM kullanıcısı seçimi.

model DomainEvent {

### 3.2 DomainEvent Outbox Modülü (`src/lib/domain-events.ts`)

```typescript
// src/lib/domain-events.ts
import { Prisma } from "@prisma/client";
import { prisma } from "@/lib/prisma";

export type DomainEventType =
  | "TASK_CREATED"
  | "TASK_STATE_CHANGED"
  | "TASK_SPRINT_ADDED"
  | "TASK_SPRINT_REMOVED"
  | "TASK_COMPLETED"
  | "TASK_DUE_DATE_CHANGED"
  | "TASK_ASSIGNEE_ADDED"
  | "TASK_ASSIGNEE_REMOVED"
  | "SPRINT_STARTED"
  | "SPRINT_COMPLETED";

export interface DomainEventPayload {
  projectId: string;
  taskId?: string;
  sprintId?: string;
  actorId?: string | null;
  oldValue?: any;
  newValue?: any;
  [key: string]: any;
}

/**
 * Transaction içinde veya doğrudan Prisma client ile DomainEvent kaydı oluşturur.
 */
export async function emitDomainEvent(
  tx: Prisma.TransactionClient | typeof prisma,
  type: DomainEventType | string,
  payload: DomainEventPayload
) {
  try {
    return await tx.domainEvent.create({
      data: {
        type,
        payload: payload as Prisma.InputJsonValue,
        status: "PENDING",
      },
    });
  } catch (error) {
    // Domain event yazma hatası ana işlemi durdurmamalıdır, ancak loglanmalıdır.
    console.error(`[DomainEvent Error] Failed to emit event ${type}:`, error);
    return null;
  }
}
```

### 3.4 HMAC Doğrulama Yardımcısı (`src/lib/internal-auth.ts`)

```typescript
// src/lib/internal-auth.ts
import crypto from "crypto";

const INTERNAL_API_SECRET = process.env.INTERNAL_API_SECRET || "pulse-internal-secret-key-change-in-prod";
const MAX_DRIFT_MS = 5 * 60 * 1000; // 5 dakika

export function verifyInternalSignature(headers: Headers, bodyString: string): boolean {
  const signature = headers.get("x-agent-signature");
  const timestampStr = headers.get("x-agent-timestamp");

  if (!signature || !timestampStr) {
    return false;
  }

  const timestamp = parseInt(timestampStr, 10);
  if (isNaN(timestamp)) return false;

  const now = Date.now();
  if (Math.abs(now - timestamp) > MAX_DRIFT_MS) {
    return false; // Replay attack koruması
  }

  const message = `${timestamp}.${bodyString}`;
  const expectedSignature = crypto
    .createHmac("sha256", INTERNAL_API_SECRET)
    .update(message)
    .digest("hex");

  try {
    return crypto.timingSafeEqual(
      Buffer.from(signature, "hex"),
      Buffer.from(expectedSignature, "hex")
    );
  } catch {
    return false;
  }
}
```

### 3.5 Next.js Internal API Rotaları (`src/app/api/internal/agent/*`)

Tüm endpoint'ler gelen isteğin imzasını `verifyInternalSignature` ile doğrulamalıdır. İmzasız veya geçersiz istekler `401 Unauthorized` dönmelidir.

3. **`GET /api/internal/agent/settings`** (`src/app/api/internal/agent/settings/route.ts`):

### 3.6 Agent Ayarları Server Action (`src/actions/agent-settings.ts`)

```typescript
// src/actions/agent-settings.ts
"use server";

import { prisma } from "@/lib/prisma";
import { requireAdmin, requireMembership } from "@/lib/authz";
import { revalidatePath } from "next/cache";

export async function getProjectAgentSettings(projectId: string) {
  await requireMembership(projectId);
  return prisma.agentSettings.findMany({
    where: { projectId },
    include: { pmUser: { select: { id: true, name: true, email: true } } },
  });
}

export async function updateProjectAgentSetting(
  projectId: string,
  agentKey: string,
  data: {
    enabled?: boolean;
    config?: Record<string, any>;
    pmUserId?: string | null;
  }
) {
  await requireAdmin(projectId);

  const updated = await prisma.agentSettings.upsert({
    where: { projectId_agentKey: { projectId, agentKey } },
    update: data,
    create: {
      projectId,
      agentKey,
      enabled: data.enabled ?? true,
      config: data.config ?? {},
      pmUserId: data.pmUserId,
    },
  });

  revalidatePath(`/projects/${projectId}/settings`);
  return updated;
}

export async function getProjectPmCandidates(projectId: string) {
  await requireAdmin(projectId);
  const admins = await prisma.projectMember.findMany({
    where: { projectId, role: "ADMIN" },
    include: { user: { select: { id: true, name: true, email: true } } },
  });
  return admins.map((a) => a.user);
}
```

### 4.4 `agent/src/internal_client.py`
Next.js Internal API ile konuşan HMAC-SHA256 imzalı HTTP istemcisi:
```python
import hmac
import hashlib
import time
import json
import httpx
from src.config import settings

class InternalClient:
    def __init__(self, base_url: str = settings.INTERNAL_API_URL, secret: str = settings.INTERNAL_API_SECRET):
        self.base_url = base_url.rstrip("/")
        self.secret = secret

    def _generate_headers(self, body_str: str) -> dict:
        timestamp = str(int(time.time() * 1000))
        message = f"{timestamp}.{body_str}".encode("utf-8")
        signature = hmac.new(self.secret.encode("utf-8"), message, hashlib.sha256).hexdigest()
        return {
            "Content-Type": "application/json",
            "x-agent-signature": signature,
            "x-agent-timestamp": timestamp,
        }

    async def send_notifications(self, notifications: list) -> bool:
        body = json.dumps({"notifications": notifications})
        headers = self._generate_headers(body)
        async with httpx.AsyncClient(timeout=10.0) as client:
            resp = await client.post(f"{self.base_url}/api/internal/agent/notifications", content=body, headers=headers)
            return resp.status_code == 200

    async def get_project_settings(self, project_id: str) -> dict:
        body = ""
        headers = self._generate_headers(body)
        async with httpx.AsyncClient(timeout=10.0) as client:
            resp = await client.get(f"{self.base_url}/api/internal/agent/settings?projectId={project_id}", headers=headers)
            if resp.status_code == 200:
                return resp.json()
            return {}

    async def record_run(self, run_data: dict) -> bool:
        body = json.dumps(run_data)
        headers = self._generate_headers(body)
        async with httpx.AsyncClient(timeout=10.0) as client:
            resp = await client.post(f"{self.base_url}/api/internal/agent/runs", content=body, headers=headers)
            return resp.status_code == 200
```

### 4.5 `agent/src/poller.py` (DomainEvent SKIP LOCKED Poller)
`DomainEvent` tablosundaki `PENDING` kayıtları `FOR UPDATE SKIP LOCKED` ile okur ve işlendikten sonra `status = 'DONE'` veya `FAILED` yapar.

### 4.6 `agent/src/catchup.py` (Startup Catch-up Mantığı)
Container ayağa kalktığında:
1. `AgentSettings` tablosundan aktif olan projeleri ve agent'ları çeker.
2. `AgentRun` tablosundan her `(agentKey, projectId)` çifti için bugünkü `scheduledFor` (09:00 Europe/Istanbul) kontrol edilir.
3. Eğer bugün saat 09:00 geçmiş ve o gün için `AgentRun` kaydı yoksa, iş **bir defaya mahsus** telafi olarak tetiklenir (`status = 'SUCCESS' | 'FAILED'`).
4. `@@unique([agentKey, projectId, scheduledFor])` veritabanı kısıtı sayesinde mükerrer çalıştırma engellenir.

### 4.7 `agent/src/supervisor.py` (Agent-000 Supervisor)
Agent-000 şunları yönetir:
- Hangi projenin hangi agent'ı açık (`AgentSettings.enabled`)?
- Aynı günde aynı agent bir proje için birden fazla çalışmasın (Rate-limiting).
- Hata durumunda loglama ve `AgentRun` tablosuna `error` yazma.

### 4.8 `agent/src/main.py`
Uygulama giriş noktası:
- Veritabanı havuzunu başlatır.
- Catch-up mantığını çalıştırır (`run_startup_catchup()`).
- APScheduler'ı başlatır (Her sabah 09:00 TZ=Europe/Istanbul).
- Outbox poller loop'unu başlatır.
- Graceful shutdown yakalar (SIGINT, SIGTERM).
